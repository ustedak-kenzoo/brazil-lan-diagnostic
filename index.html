1. 측정 정보

측정 위치는 사용자가 직접 입력합니다. 조사자 이름이나 계정 로그인은 필요하지 않습니다.

대기 중 · 인터넷 연결 필요
검사 버튼은 Cloudflare 측정 서버와 실제 데이터를 송수신합니다. 매장 관리자에게 먼저 허락을 받으세요. 3명이 같은 회선에서 측정할 때는 순차 실행하세요. 측정 결과는 Cloudflare에도 수집될 수 있습니다. 게임 실행 중의 패킷 손실률은 브라우저에서 확인할 수 없습니다. 측정하지 않은 값은 빈칸(N/A)으로 남깁니다.

3. PC 사양 직접 입력

Windows 설정 → 시스템 → 정보에서 CPU/RAM/OS 확인, 작업 관리자 → 성능에서 GPU 확인. 브라우저는 정확한 모델을 자동으로 읽을 수 없습니다.

브라우저 CSS 화면 크기이며 실제 모니터 해상도와 다를 수 있음. Windows 배율의 영향을 받습니다.

4. Google Sheets에 결과 누적

Google Apps Script 주소가 미리 입력되어 있습니다. 매장 PC에서는 매장명·PC 사양을 입력하고 측정 후 전송 버튼만 누르면 됩니다. Google 로그인은 하지 않습니다.

전송 대기 중
전송 버튼은 실제 결과를 Google Sheets에 누적합니다. 전송 후 시트에 저장됐는지 조회해 확인합니다. 확인 실패 시 JSON 파일로 백업하세요. PIN은 브라우저에 저장하지 않으며, 공용 PC에서는 사용 후 페이지를 닫으세요. 공개 GitHub 저장소에 PIN을 넣지 마세요.

5. 여러 PC 결과 한 번에 합치기

각 PC에서 받은 JSON 파일을 한 폴더에 모은 뒤 여러 파일을 동시에 선택하세요. 매장별로 자동 합쳐집니다. 파일은 브라우저 안에서만 처리됩니다.
